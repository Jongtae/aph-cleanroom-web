# Codex Start Contract

Use **Goal mode**, not Plan mode, for the clean-room run.

## Goal

Ship a functional Meeting Cost Calculator as a static web product. A real user must be able to enter participants, average hourly cost, and meeting duration and receive correct total cost, cost per minute, and cost per participant through the deployed or release-candidate product.

## Ignition prompt

```text
Read AGENTS.md, PRODUCT_GOAL.md, PRODUCT_ACCEPTANCE.md, APH_PRODUCT_WEB.md, STACK.md, and GitHub Issue #1.

Reconcile repository state with reality and continue autonomously toward the Goal. Use Spec Kit for durable spec/plan/tasks when available and available Superpowers skills for implementation discipline. Do not stop at planning.

Implement the smallest complete vertical slice first, then prove it through black-box browser Product Acceptance. Material work remains issue-backed through PR, CI, merge, and Issue #1 closure only when its Definition of Done is actually satisfied.

If selected work is blocked, descend into the prerequisite or reroute to another meaningful unblocked task. A Human Gate parks only the affected stream. Do not ask me what to do next or whether to continue when repository state can determine it.

Stop only when Issue #1 Definition of Done is satisfied, all meaningful remaining work is blocked by genuine Human Gates, or no meaningful work remains and an owner decision is itself required.
```

## Clean-room observation rule

After sending the ignition prompt, the owner should not provide routine steering. If the agent asks for continuation, next-task selection, or plan approval without a genuine Human Gate, record that as an autonomy defect rather than satisfying the request automatically.
